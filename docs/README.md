## オフラインの確かめ方

1. https://hiros0921.github.io/csv-tidy/ を開く
2. 画面上部に「**ネットワークを切っても、そのまま使えます。**」が出るまで待つ
   （Service Worker が保存し終わった合図。数秒）
3. **Wi-Fi を切る**（または機内モード）
4. **ページを再読み込み** → 開けば成功
5. CSV をドロップ → 検出 → 直す → 再検査 → 書き出し。最後まで通れば完了

3で切らずに再読み込みしてしまうと、キャッシュから返ったのか
ネットワークから返ったのか区別がつきません。**切ってから**確かめてください。

## Network タブの撮り方（同じ手順で再現できます）。

1. `npm run build && npx vite preview`
2. 開発者ツールを開き、**Network** タブで **Disable cache** を入れる
3. ページを再読み込み
4. CSV をドロップ → 検出を待つ → どこか直す → 再検査 → 書き出し
5. 一覧を撮る。**Domain 列**を出しておくと、外部が無いことが一目で分かる
